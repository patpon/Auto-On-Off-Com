Auto On/Off — ตั้งเวลาเปิด-ปิดคอมพิวเตอร์อัตโนมัติ
By Aj พชรพล
==================================================

[ ติดตั้ง — ทำครั้งเดียวต่อเครื่อง ]
1. คลิกขวาไฟล์ ZIP > Properties > ติ๊ก "Unblock" > OK   (ถ้าไม่มีช่องนี้ ข้ามได้)
2. แตกไฟล์ไปไว้ที่ C:\AutoOnOff   (ที่อยู่โฟลเดอร์ห้ามมีภาษาไทย)
3. ดับเบิลคลิก Start-AutoOnOff.bat > กด Yes
4. ตั้งเวลาและวัน > วิธีปิดเลือก "Hibernate" > กด "บันทึกและเปิดใช้งาน"
5. ดูกล่องสถานะด้านล่าง: ต้องไม่มีเครื่องหมาย ⚠

[ ทดสอบก่อนใช้จริง — แนะนำ 1 เครื่องต่อ 1 รุ่น ]
- ตั้งปิด = อีก 3 นาที, เตือนก่อน 1 นาที, ตั้งเปิด = หลังเวลาปิด 8 นาที, เลือกเฉพาะวันนี้
- เครื่องดับ แล้วติดเองตามเวลา = ผ่าน  (จออาจยังมืด ให้ขยับเมาส์)
- ไม่ติดเอง: กดปุ่ม Power (งานที่เปิดค้างยังอยู่ครบ) = เครื่องรุ่นนี้ปลุกจาก Hibernate ไม่ได้
- ทดสอบเสร็จ อย่าลืมตั้งเวลาจริงทับ

[ ใช้งานประจำวัน ]
- ถึงเวลาปิดจะมีหน้าต่างนับถอยหลัง
  ยังทำงานอยู่ กด "ยกเลิก — ยังใช้งานอยู่"  (ยกเลิกเฉพาะครั้งนั้น)
- แก้เวลา: เปิด Start-AutoOnOff.bat ใหม่ แก้แล้วกดบันทึก
- เลิกใช้: เปิดโปรแกรม > กด "ยกเลิกทั้งหมด"

[ วิธีปิด เลือกแบบไหนดี ]
- Hibernate (แนะนำ)  ไฟดับเหมือนปิดสนิท, งานที่เปิดค้างยังอยู่, ปลุกตามเวลาได้
- Sleep              ยังกินไฟเล็กน้อย, ปลุกตามเวลาได้
- Shutdown           ปิดสนิท, Windows ปลุกเองไม่ได้ (ต้องตั้งใน BIOS หรือใช้ Wake-on-LAN)

[ ติดตั้งหลายเครื่องพร้อมกัน — สำหรับฝ่ายไอที ]
แก้เวลาใน examples\office.json แล้วรันใน PowerShell แบบ Run as administrator:

  powershell -ExecutionPolicy Bypass -File C:\AutoOnOff\AutoOnOff.ps1 -Apply -ConfigFile C:\AutoOnOff\examples\office.json

[ แก้ปัญหา ]
- ประวัติการทำงาน:            C:\ProgramData\AutoOnOff\log.txt
- เครื่องรองรับ Hibernate ไหม:  พิมพ์ powercfg /a ใน PowerShell
- ไม่มี ⚠ แต่ไม่ตื่นเอง:         เครื่องรุ่นนั้นไม่รองรับ ลองโหมด Sleep หรือใช้ Wake-on-LAN
                               (tools\Send-WakeOnLan.ps1 รันจากเครื่องที่เปิดตลอด)
